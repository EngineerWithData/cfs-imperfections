The main reference for this data is:

D. Padilla-Llano (2015), A Framework for Cyclic Simulation of Thin-Walled  Cold-Formed Steel Members in Structural Systems", Ph.D Dissertation, http://hdl.handle.net/10919/52904

Axial Specimen Imperfections:
- mIMPERFECT.mat = Manually Measured Imperfections (via Dial Gages and Precision Rail)
- pgIMPERFECT3.mat = Imperfections Measured Using Photogrammetry Method
- plotImpPGandDG2a.m = Script to plot Graphics Similar to those in D.Padilla-Llano Dissertation. Can be use to inform the structure of the mat file

Flexural Member Immperfections:
- mIMPFlex.mat = Manually Measured Imperfections (via Dial Gages and Precission Rail)
- pgIMPFlex.mat = Imperfections Measured Using Photogrammetry Method
- plotImpPGandDG2a4Flex.m = Script to plot Graphics Similar to those in D.Padilla-Llano Dissertation. Can be use to inform the structure of the mat file
